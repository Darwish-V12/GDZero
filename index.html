GDZero

Wi-Fi CSI Motion Detection V2 · Radar Dashboard
Turn an ESP32 into a motion sensor using the Wi-Fi signals already traveling through your room.
No camera. No PIR sensor. No additional sensing hardware.
🎯 Military Radar UIA dot-skeleton figure walks the radar while motion is detected, breathes when someone is present.
📈 60s Motion LogA live timeline records every detection event of the last 60 seconds.
🛰 Auto Demo ModeNo device reachable? The radar simulates a target automatically — great for practice.
⛶ FullscreenOne click turns the whole screen into the radar for live presentations.

Install GDZero v2

Connect your ESP32 with a USB data cable and install the latest firmware (with the new Radar Dashboard built in) directly from your browser. No tools, no compilation, no ESP-IDF needed.

Requires a compatible ESP32 and a browser that supports Web Serial, such as Google Chrome or Microsoft Edge on desktop.

After Installation

1
Connect to DrWalls-Setup After installation, the ESP32 creates its own temporary Wi-Fi network.
2
Configure Wi-Fi The setup page should open automatically. Select your Wi-Fi network and enter its password.
3
Open the CSI Radar Once connected, open http://drwalls.local from a device on the same network — the v2 radar dashboard appears. A green LINK indicator means the dashboard is connected to the device; amber DEMO means it is simulating a target.
4
Move! GDZero analyzes changes in Wi-Fi CSI data. On movement the status switches to MOTION DETECTED, the dot skeleton starts walking and the detection is stamped into the 60-second motion log.
GDZero is an experimental maker project. Detection performance can vary depending on ESP32 placement, router position, room layout, interference, and the surrounding environment.
